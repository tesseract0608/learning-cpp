# Learning C++

This repository documents my structured learning of C++ with a focus on
Data Structures and Algorithms.

## Purpose
- Build strong fundamentals in problem solving
- Write clean, readable, and well-documented C++ code
- Prepare for open-source contributions and Google Summer of Code (GSoC)

## Folder Structure
- Arrays/        → Array-based problems and patterns
- BinarySearch/  → Binary search and related problems
- Recursion/     → Recursion and basic dynamic programming

## Coding Principles
- Clarity over clever tricks
- Proper time and space complexity analysis
- Meaningful variable and function names

## Long-Term Goal
To contribute to open-source projects and participate in Google Summer of Code.
